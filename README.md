## À propos

<img align="right" alt="Développeur au travail" width="320" src="assets/hero.gif" />

Étudiant en informatique au **Collège de Maisonneuve** (Montréal), je conçois des applications web complètes : interface, API REST, base de données et déploiement.

- 🔭 **En ce moment** : CrimeTracker, une application temps réel pour la coordination policière (React, Express, PostgreSQL, Socket.io)
- 🔐 **Sujets qui m'intéressent** : authentification et sécurité, temps réel, conteneurisation, IA
- 🧪 **Ma façon de travailler** : tests automatisés, CI avec GitHub Actions, documentation d'API avec Swagger
- 🤝 **Je cherche** : stages, projets d'équipe et contributions open source
