# Dr. Arobase — Glitch Edition

This is a stylized, glitch-themed profile and a tiny demo site in `glitch-site/`.

Preview the banner/avatar (SVG) in `assets/` and open `glitch-site/index.html` locally to see the effect.

How to run locally:

```bash
# from repo root
python -m http.server 8000
# then open http://localhost:8000/glitch-site/
```

Deploy options:
- Enable GitHub Pages (Settings → Pages → Branch `main` → / (root) )
- Import the project on https://glitch.com/ to edit live

Replace placeholders in `assets/` with your screenshots to personalize.

Enjoy the glitch vibes ✨
